# K1 UAMMD validation harness

`kg_assoc_k1` is the many-sticker K1 analogue of the LAMMPS isolated WCA fluid: 256 valence-one stickers, `rho=.05`, `T=1`, `dt=.005`, `nu0=20`, Langevin damping 2, 20,000 WCA-only warm-up steps, then 100,000 production steps. UAMMD does not reproduce LAMMPS `nve/limit` exactly: random particles first undergo a bounded DPD soft push-off (5,000 steps by default), with association disabled, before the normal WCA/Langevin equilibration. Persistent-ID minimum-image diagnostics report the separation and finite position/velocity status after the push-off and WCA equilibration; a state below 0.8 is rejected before WCA. Chemistry candidates are host cell-list pairs built only every `Nevery` from a synchronized position snapshot; storage slots are converted to persistent `ParticleData` IDs before canonicalization, so spatial reordering cannot change kinetic hashes. Edges are then deduplicated before the exact LAMMPS hash-ordered kinetic sweep. This avoids O(N^2) production search and no host/device transfer occurs each production MD step.

On a CUDA host: `make -C examples/KG_Assoc`, then `./examples/KG_Assoc/k1/run_k1_campaign.sh ./examples/KG_Assoc/kg_assoc_k1 pilot`. The pilot is explicitly 20,000 warm-up plus 10,000 production steps and uses `pilot_` filenames, so it cannot skip a 100,000-step result. Inspect `k1/results/*.state`, then use `baseline` or `full`; analyze with `python3 examples/KG_Assoc/analysis/analyze_k1.py 'examples/KG_Assoc/k1/results/*.state' --summary examples/KG_Assoc/k1/results/k1.csv`.

State rows are timestep, physical time, free stickers, active dimers, creations, and breaks. The executable rejects mass/event invariants. The analyzer uses exact finite-N pair exposure, trapezoidal physical-time integrals, reports rectangle exposure differences, and writes replica and condition CSVs. `Nevery=50` samples every 100 steps by default, so its exposure diagnostic is intentionally weaker; events remain exact.
